# AR Sky

Browser-based augmented reality sky viewer.

Open `index.html` on a phone (HTTPS required for sensors) and grant location + motion permissions. Point the phone at the sky to see bright stars overlaid in real time.

## Features (starter)
- Geolocation
- Device orientation (heading + pitch)
- Bright star catalog overlay (Sirius, Vega, Polaris, etc.)
- Simple altitude/azimuth projection

## Next steps
- Full Yale Bright Star / Hipparcos catalog
- Sun, Moon, and planets
- Constellation lines
- Camera background overlay
- Night mode + calibration

Built with free public star data and standard Web APIs.
